# Project 1 reference modules

These files are unchanged copies of modules from Project 1 ([razvan-m-30/nba-europe-demand-plan](https://github.com/razvan-m-30/nba-europe-demand-plan), commit `498752b5788f7a548275005f313d25a36c0b0081`), kept as the source for porting into the Databricks pipeline. `process_interest.py` holds the weekly aggregation and indexing logic; `analogs.py` holds the baseline, uplift, peak, half-life and persistence logic. They are reference only and are not run in Project 2.
